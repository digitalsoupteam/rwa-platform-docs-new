# Join a Pool

Participating in a pool means contributing HOLD tokens in exchange for RWA tokens that represent your stake. The pool's AMM determines the exchange rate, and tranches automate the flow of returns back to you.

## Find a Pool

Browse available pools on the platform. Each pool shows:

- **Business name and description** — who is raising funds
- **Risk score** — AI-evaluated risk level
- **Pool parameters** — target amount, current progress, fees
- **Tranche schedule** — expected return timeline
- **Charts** — price history and volume data

You can also [query pools](/docs/api/rwa/pools/get-pools) via GraphQL with filters (e.g. by business, risk score, or deployment status).

## Review Tranches

Before contributing, review the pool's tranche structure — see [Tranches & Distributions](/docs/pools/tranches) for the full mechanics:

- **Outgoing tranches** — when the business will claim funds (affects pool reserves)
- **Incoming tranches** — when the business is expected to return funds
- **Bonus** — additional rewards if the business exceeds its obligations

## Contribute

To contribute, call `Pool.mint()` on-chain:

```solidity
function mint(
    uint256 rwaAmount,      // How many RWA tokens you want
    uint256 maxHoldAmount,  // Maximum HOLD you're willing to spend
    uint256 validUntil,     // Transaction deadline
    bool allowPartial       // Accept partial fill if supply is limited
) external nonReentrant
```

The pool calculates the cost using the AMM formula:

```
holdAmount = (k / (virtualRwaReserve - rwaAmount)) - (virtualHoldReserve + realHoldReserve)
fee = holdAmount × entryFeePercent / 10000
totalCost = holdAmount + fee
```

You need to approve the HOLD tokens first, then call `mint`:

```tsx
import { useReadContract, useWriteContract, encodeFunctionData } from 'wagmi';
import { parseAbi } from 'viem';

// ABI fragments
const poolAbi = parseAbi([
  'function estimateMint(uint256 rwaAmount, bool allowPartial) view returns (uint256 holdAmountWithFee, uint256 fee, uint256 actualRwaAmount)',
  'function mint(uint256 rwaAmount, uint256 maxHoldAmount, uint256 validUntil, bool allowPartial)',
]);
const holdAbi = parseAbi([
  'function approve(address spender, uint256 amount) returns (bool)',
]);

// 1. Estimate cost via useReadContract
const { data: estimate } = useReadContract({
  address: poolAddress,
  abi: poolAbi,
  functionName: 'estimateMint',
  args: [rwaAmount, true],
});

const holdAmountWithFee = estimate?.[0] ?? 0n;

// 2. Approve HOLD for pool via useWriteContract
const { writeContract: approve } = useWriteContract();

const handleApprove = () => {
  approve({
    address: holdTokenAddress,
    abi: holdAbi,
    functionName: 'approve',
    args: [poolAddress, holdAmountWithFee],
  });
};

// 3. Mint via useWriteContract
const { writeContract: mint } = useWriteContract();

const handleMint = () => {
  mint({
    address: poolAddress,
    abi: poolAbi,
    functionName: 'mint',
    args: [
      rwaAmount,
      holdAmountWithFee,
      BigInt(Math.floor(Date.now() / 1000) + 600), // validUntil (10 min)
      true, // allowPartial
    ],
  });
};

// Prepare calldata with encodeFunctionData (alternative)
const mintCalldata = encodeFunctionData({
  abi: poolAbi,
  functionName: 'mint',
  args: [
    rwaAmount,
    holdAmountWithFee,
    BigInt(Math.floor(Date.now() / 1000) + 600),
    true,
  ],
});
```

For the full function reference, see [Contract Reference — Pool](/docs/smart-contracts/contract-reference#pool).

### Estimating the Cost

Before calling `mint`, use `estimateMint` to calculate the required HOLD amount:

```solidity
function estimateMint(
    uint256 rwaAmount,
    bool allowPartial
) public view returns (uint256 holdAmountWithFee, uint256 fee, uint256 actualRwaAmount)
```

The function returns:
- **`holdAmountWithFee`** — total HOLD needed (including the entry fee)
- **`fee`** — the entry fee portion
- **`actualRwaAmount`** — the actual RWA amount you will receive (may differ from `rwaAmount` if partial fill is allowed)

### Pool Parameters

- **`entryFeePercent`** — a fee (in basis points, 1/10000) charged on mint. It is added to the calculated HOLD amount: `fee = holdAmount × entryFeePercent / 10000`.
- **`liquidityCoefficient`** — used during pool initialization to set virtual reserves for the constant product AMM: `virtualHoldReserve = expectedHoldAmount × liquidityCoefficient` and `virtualRwaReserve = expectedRwaAmount × (liquidityCoefficient + 1)`.
- **`priceImpactPercent`** — declared in the contract but currently does not affect the AMM calculations. The pool uses a pure constant product formula.

## Exit the Pool

To exit, call `Pool.burn()`:

```solidity
function burn(
    uint256 rwaAmount,       // RWA tokens to burn
    uint256 minHoldAmount,   // Minimum HOLD to accept
    uint256 minBonusAmount,  // Minimum bonus to accept
    uint256 validUntil       // Transaction deadline
) external nonReentrant
```

```tsx
import { useReadContract, useWriteContract, encodeFunctionData } from 'wagmi';
import { parseAbi } from 'viem';

// ABI fragments
const poolAbi = parseAbi([
  'function estimateBurn(uint256 rwaAmount) view returns (uint256 holdAmount, uint256 holdFee, uint256 bonusAmount, uint256 bonusFee, uint256 eligibleRwa)',
  'function burn(uint256 rwaAmount, uint256 minHoldAmount, uint256 minBonusAmount, uint256 validUntil)',
]);
const rwaAbi = parseAbi([
  'function approve(address spender, uint256 amount) returns (bool)',
]);

// 1. Estimate return via useReadContract
const { data: estimate } = useReadContract({
  address: poolAddress,
  abi: poolAbi,
  functionName: 'estimateBurn',
  args: [rwaAmount],
});

const holdAmount = estimate?.[0] ?? 0n;
const bonusAmount = estimate?.[2] ?? 0n;

// 2. Approve RWA for pool via useWriteContract
const { writeContract: approveRwa } = useWriteContract();

const handleApproveRwa = () => {
  approveRwa({
    address: rwaTokenAddress,
    abi: rwaAbi,
    functionName: 'approve',
    args: [poolAddress, rwaAmount],
  });
};

// 3. Burn via useWriteContract
const { writeContract: burn } = useWriteContract();

const handleBurn = () => {
  burn({
    address: poolAddress,
    abi: poolAbi,
    functionName: 'burn',
    args: [
      rwaAmount,
      holdAmount,     // min HOLD to receive
      bonusAmount,    // min bonus to receive
      BigInt(Math.floor(Date.now() / 1000) + 600), // validUntil (10 min)
    ],
  });
};

// Prepare calldata with encodeFunctionData (alternative)
const burnCalldata = encodeFunctionData({
  abi: poolAbi,
  functionName: 'burn',
  args: [
    rwaAmount,
    holdAmount,
    bonusAmount,
    BigInt(Math.floor(Date.now() / 1000) + 600),
  ],
});
```

```solidity
function estimateBurn(
    uint256 rwaAmount
) public view returns (
    uint256 holdAmountWithoutFee,
    uint256 holdFee,
    uint256 bonusAmountWithoutFee,
    uint256 bonusFee,
    uint256 eligibleRwaAmount
)
```

The function returns:
- **`holdAmountWithoutFee`** — the base HOLD amount you receive (after deducting the exit fee)
- **`holdFee`** — the exit fee charged on the base amount
- **`bonusAmountWithoutFee`** — the bonus HOLD amount (after deducting the exit fee)
- **`bonusFee`** — the exit fee charged on the bonus
- **`eligibleRwaAmount`** — how much of your RWA is eligible for the bonus

### Exit Fees and Bonuses

- **`exitFeePercent`** — a fee (in basis points, 1/10000) charged on burn. It applies to both the base HOLD amount and any bonus: `holdFee = totalHoldAmount × exitFeePercent / 10000` and `bonusFee = totalBonusAmount × exitFeePercent / 10000`.
- **Bonuses** — if the pool has `awaitingBonusAmount` and bonuses are unlocked (the entry period has ended and the target was reached), a portion of your RWA may be redeemed with an additional HOLD bonus. The bonus is proportional to your share of the eligible RWA.

You receive your proportional share of returned funds plus any available bonus, minus exit fees. See [Fees](/docs/fees/overview) for the full breakdown of all protocol fees.
