# Webhooks

> **⚠️ Under development**
>
> The Webhooks service is not implemented yet. This section describes plans for the future.

Webhooks will allow you to receive real-time HTTP notifications about platform events. Instead of polling the GraphQL API, you will be able to register a webhook endpoint and receive push notifications on your server.

At the moment the service is in the design stage. Stay tuned for documentation updates — details will appear after implementation.
