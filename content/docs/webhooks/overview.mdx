# Webhooks

> **⚠️ В разработке**
>
> Webhooks-сервис пока не реализован. Данный раздел описывает планы на будущее.

Webhooks позволят получать real-time HTTP-уведомления о событиях на платформе. Вместо опроса GraphQL API можно будет зарегистрировать webhook-эндпоинт и получать push-уведомления на свой сервер.

На данный момент сервис находится в стадии проектирования. Следите за обновлениями документации — подробности появятся после реализации.
