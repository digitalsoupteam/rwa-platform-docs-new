## Example

Update the name of an existing assistant:

```bash
curl -X PATCH "https://api.example.com/v1/assistants/asst_abc123" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Updated Trading Assistant"
  }'
```

```json
{

  "user_id": "user_789",

}
```
