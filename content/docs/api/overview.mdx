# API Reference Overview

The RWA Platform provides a unified GraphQL API through the Gateway, built on **Elysia** with **GraphQL Yoga**. Authentication uses **JWT** (access + refresh tokens). Internal communication between microservices runs through **Eden Treaty** (a proxy client). Subscriptions work over **SSE** (Server-Sent Events) using **Redis Pub/Sub**.

## Gateway Architecture

- **HTTP server**: Elysia (Bun)
- **GraphQL engine**: GraphQL Yoga
- **Authentication**: JWT (access token in the Authorization header, refresh token via a mutation)
- **Proxy client**: Eden Treaty for calling internal microservices
- **Subscriptions**: SSE over Redis Pub/Sub (channels `priceUpdates`, `transactionUpdates`, `poolDeployed`, `countdown`)
- **Context**: holds user information, Redis and Eden clients, caching and validation services

## Available GraphQL Modules

The schema defines **17 modules** in total. Each module provides a set of Queries, Mutations and/or Subscriptions.

| Module | Description | Query | Mutation | Subscription |
|--------|----------|-------|----------|-------------|
| **auth** | Authentication and token management | `getUserTokens` | `authenticate`, `refreshToken`, `revokeTokens` | — |
| **ai-assistant** | AI assistants and messages | `getAssistant`, `getUserAssistants`, `getMessage`, `getMessageHistory` | `createAssistant`, `updateAssistant`, `deleteAssistant`, `createMessage`, `updateMessage`, `deleteMessage` | — |
| **testnet-faucet** | Testnet faucet for tokens | `getHistory`, `getUnlockTime` | `requestGas`, `requestHold`, `requestPlatform` | — |
| **signers-manager** | Signature management | `getSignatureTask` | — | — |
| **rwa** | Real-world assets (businesses and pools) | `getBusiness`, `getBusinesses`, `getPool`, `getPools` | `createBusiness`, `createBusinessWithAI`, `editBusiness`, `updateBusinessRiskScore`, `requestBusinessApprovalSignatures`, `rejectBusinessApprovalSignatures`, `createPool`, `createPoolWithAI`, `editPool`, `updatePoolRiskScore`, `requestPoolApprovalSignatures`, `rejectPoolApprovalSignatures` | `poolDeployed` |
| **documents** | Documents and folders | `getDocument`, `getDocuments`, `getFolder`, `getFolders` | `updateDocument`, `deleteDocument`, `createFolder`, `updateFolder`, `deleteFolder` | — |
| **gallery** | Galleries and images | `getGallery`, `getGalleries`, `getImage`, `getImages` | `createGallery`, `updateGallery`, `deleteGallery`, `updateImage`, `deleteImage` | — |
| **faq** | FAQ (topics and answers) | `getFaqTopic`, `getFaqTopics`, `getFaqAnswer`, `getFaqAnswers` | `createFaqTopic`, `updateFaqTopic`, `deleteFaqTopic`, `createFaqAnswer`, `updateFaqAnswer`, `deleteFaqAnswer` | — |
| **blog** | Blogs and posts | `getBlog`, `getBlogs`, `getPost`, `getPosts` | `createBlog`, `updateBlog`, `deleteBlog`, `createPost`, `updatePost`, `deletePost` | — |
| **questions** | Questions and answers (Q&A) | `getTopic`, `getTopics`, `getQuestion`, `getQuestions` | `createTopic`, `updateTopic`, `deleteTopic`, `createQuestion`, `updateQuestionText`, `createQuestionAnswer`, `updateQuestionAnswer`, `deleteQuestion`, `toggleQuestionLike` | — |
| **portfolio** | Portfolio (balances and transactions) | `getBalances`, `getTransactions` | — | — |
| **company** | Companies and members | `getCompany`, `getCompanies` | `createCompany`, `updateCompany`, `deleteCompany`, `addMember`, `removeMember`, `grantPermission`, `revokePermission` | — |
| **charts** | Charts and price data | `getRawPriceData`, `getOhlcPriceData`, `getPoolTransactions`, `getVolumeData` | — | `priceUpdates`, `transactionUpdates` |
| **reactions** | Reactions (likes/dislikes) | `getEntityReactions`, `getReactions` | `setReaction`, `resetReaction` | — |
| **loyalty** | Loyalty (referrals, fees) | `getFees`, `getReferrals`, `getReferrerWithdraws`, `getReferrerClaimHistory` | `registerReferral`, `createReferrerWithdrawTask` | — |
| **dao** | DAO (staking, voting, treasury) | `getStaking`, `getProposals`, `getVotes`, `getStakingHistory`, `getTimelockTasks`, `getTreasuryWithdraws` | — | — |
| **demo** | Demo subscriptions | — | — | `countdown` |

> File uploads are handled via REST, not GraphQL: `POST /api/documents/createDocument`, `POST /api/gallery/createImage` (multipart/form-data).

## Planned Modules

The following modules are planned and not yet implemented in the Gateway:
- **ai-evaluator**
- **api-keys**

## Base Types

The schema defines common scalars, enums and inputs:
- **Scalar**: `JSON`
- **Enum**: `SortDirection` (`asc`, `desc`)
- **Input**: `SortFieldInput`, `PaginationInput`, `SocialLinkInput`
- **Type**: `SocialLink`
