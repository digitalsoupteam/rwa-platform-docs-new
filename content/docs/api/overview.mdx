# API Reference Overview

RWA Platform предоставляет единый GraphQL API через Gateway, построенный на **Elysia** с **GraphQL Yoga**. Аутентификация осуществляется через **JWT** (access + refresh токены). Внутренняя коммуникация между микросервисами реализована через **Eden Treaty** (прокси-клиент). Подписки (Subscriptions) работают через **SSE** (Server-Sent Events) с использованием **Redis Pub/Sub**.

## Архитектура Gateway

- **HTTP-сервер**: Elysia (Bun)
- **GraphQL-движок**: GraphQL Yoga
- **Аутентификация**: JWT (access token в заголовке Authorization, refresh token через мутацию)
- **Прокси-клиент**: Eden Treaty для вызовов внутренних микросервисов
- **Подписки**: SSE через Redis Pub/Sub (каналы `priceUpdates`, `transactionUpdates`, `poolDeployed`, `countdown`)
- **Контекст**: содержит информацию о пользователе, клиенты Redis и Eden, сервисы кэширования и валидации

## Базовые типы

В схеме определены общие скаляры, енумы и инпуты:
- **Scalar**: `JSON`
- **Enum**: `SortDirection` (`asc`, `desc`)
- **Input**: `SortFieldInput`, `PaginationInput`, `SocialLinkInput`
- **Type**: `SocialLink`
