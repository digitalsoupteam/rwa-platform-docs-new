# Staking

Staking allows you to deposit PlatformTokens in exchange for governance voting power and rewards.

## How Staking Works

The `DaoStaking` contract manages staking:

```solidity
function stake(uint256 amount) external nonReentrant
function unstake(uint256 amount) external nonReentrant
```

When you stake:

1. Any pending rewards are automatically claimed and reinvested (reinvestment)
2. PlatformTokens are transferred from your wallet to the staking contract
3. Your staked amount is recorded and converted to voting power (1:1 ratio)
4. Your staking timestamp is set, starting reward accrual

```javascript
// Approve PlatformToken for DaoStaking contract
await platformToken.approve(daoStakingAddress, amount);

// Stake
await daoStaking.stake(amount);
```

## Staking Rewards

Rewards are calculated based on:

- **Annual reward rate** — **10%** (1000 bps, `daoStakingAnnualRewardRate` in Config)
- **Staking duration** — time since last stake or reinvest
- **Available rewards** — contract balance minus total user deposits

```solidity
annualReward = stakedAmount × annualRewardRate / 10000
pendingReward = annualReward × stakingDuration / 365 days
// Capped by available rewards in the pool
if (pendingReward > availableRewards) pendingReward = availableRewards
```

For example, if you stake **50,000 PlatformToken** and hold for **30 days**:

```
annualReward = 50,000 × 10% = 5,000 PlatformToken
pendingReward = 5,000 × 30 / 365 ≈ 410.96 PlatformToken
```

After 30 days you earn **~411 PlatformToken** on top of your 50,000.

If you hold for a full year:

```
pendingReward = 5,000 × 365 / 365 = 5,000 PlatformToken
```

Total: **55,000 PlatformToken** (10% APY).

Rewards are automatically reinvested when you stake more or partially unstake.

## Unstaking

To unstake, call `unstake(amount)`:

```javascript
await daoStaking.unstake(amount);
```

- **Full unstake** — if you unstake your entire position, you receive your staked tokens plus all accrued rewards
- **Partial unstake** — if you unstake part of your position, the remaining amount plus rewards are automatically reinvested

**Constraint:** You cannot unstake while your voting lock is active (tokens locked until voted proposal ends).

## Voting Lock

When you vote on a proposal, `Governance.vote()` calls `DaoStaking.lock(user, proposal.endTime)`, which locks your staked tokens until the proposal's end time. The `lock` function is callable only by the Governance contract (via `addressBook.requireGovernance`) and updates the lock only if the new `unlockTimestamp` is greater than the current `votingLockTimestamp[user]`:

```solidity
function lock(address user, uint256 unlockTimestamp) external {
    addressBook.requireGovernance(msg.sender);
    require(stakedAmount[user] > 0, "No staked tokens");
    require(unlockTimestamp > block.timestamp, "Invalid unlock timestamp");

    // Only extends — never shortens
    if (unlockTimestamp > votingLockTimestamp[user]) {
        votingLockTimestamp[user] = unlockTimestamp;
    }

    EventEmitter eventEmitter = addressBook.eventEmitter();
    eventEmitter.emitDaoStaking_TokensLocked(user, votingLockTimestamp[user]);
}
```

This means:
- After voting, you cannot unstake until the proposal's `endTime`
- If you vote on multiple proposals, your lock extends to the latest `endTime`
- The lock only extends, never shortens

## View Functions

```javascript
const staked = await daoStaking.stakedAmount(user);
const votingPower = await daoStaking.getVotingPower(user);
const totalVotingPower = await daoStaking.getTotalVotingPower();  // = totalSupply
const pendingRewards = await daoStaking.calculatePendingRewards(user);
const availableRewards = await daoStaking.getAvailableRewards();
```

Total voting power for quorum calculations is based on the total PlatformToken supply (not just staked amount).

## State Variables

The `DaoStaking` contract maintains the following key state variables:

- **`stakedAmount[user]`** — mapping of user address to their staked token amount
- **`votingLockTimestamp[user]`** — mapping of user address to their voting lock expiration timestamp
- **`totalUserDeposits`** — total amount of tokens deposited by all users across the contract
- **`stakingTimestamp[user]`** — mapping of user address to the timestamp of their last stake or reinvest

## Events

The `DaoStaking` contract emits the following events:

```solidity
event DaoStaking_TokensStaked(address indexed emittedFrom, address indexed staker, uint256 amount, uint256 newVotingPower);
event DaoStaking_TokensUnstaked(address indexed emittedFrom, address indexed staker, uint256 amount, uint256 rewardsReceived, uint256 newVotingPower);
event DaoStaking_TokensLocked(address indexed emittedFrom, address indexed user, uint256 unlockTimestamp);
```

- **`DaoStaking_TokensStaked`** — emitted when a user stakes tokens, includes the contract address (`emittedFrom`), staker address, staked amount, and the new total voting power after reinvestment
- **`DaoStaking_TokensUnstaked`** — emitted when a user unstakes tokens, includes the contract address (`emittedFrom`), staker address, unstaked amount, rewards received, and the new voting power
- **`DaoStaking_TokensLocked`** — emitted when a user's tokens are locked after voting, includes the contract address (`emittedFrom`), user address, and unlock timestamp
